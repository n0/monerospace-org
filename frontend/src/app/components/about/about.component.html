About xmr-space

xmr-space is a fork of mempool.space retargeted to Monero. It surfaces what the chain alone proves — height, hashrate, mempool, fee tiers, ring information, RingCT type — and stops there. Amounts and recipients are hidden by Monero's RingCT and stay hidden in the default render.

Privacy by default

Every transaction-detail page blurs the sensitive fields by design and offers three opt-in reveal flows for participants:

  • I received this tx — your view key + sub-address, decryption runs locally in the browser. The key never leaves the page.
  • I sent this tx — verify payment — a tx_proof signature (generated by the sender's wallet, non-secret by design) plus the recipient address. The server verifies; no keys involved.
  • I have the tx_secret_key — the one-time per-tx scalar, again decrypted locally.
Daemon

By default this instance talks to https://xmr-node.cakewallet.com:18081 (Cake Wallet's public node). Operators can point at any monerod that exposes the standard JSON-RPC; see the .env.sample file.
